# AI Content Assistant

Небольшой MVP AI-помощника для создания контента. Пользователь заполняет короткий бриф, а приложение формирует пять идей для Reels, сценарий, текст поста и промпт для изображения.

## Запуск

Это статическое приложение без зависимостей и сборки.

1. Откройте терминал в папке проекта.
2. Запустите локальный сервер:

   ```bash
   python3 -m http.server 8080
   ```

3. Откройте [http://localhost:8080](http://localhost:8080) в браузере.

Для остановки сервера используйте `Ctrl+C`.

## Структура

```text
├── index.html   # разметка интерфейса
├── styles.css   # адаптивные стили
└── app.js       # генерация и вывод контента
```

## Как пользоваться

Введите нишу, тему и выберите цель. Нажмите «Создать контент», чтобы получить готовую основу для публикации. Тексты созданы как демонстрационные шаблоны: их легко отредактировать под голос бренда и фактические детали.
